# 校园建造 720 天

虚拟职业技术学院新校区的施工全过程实时 3D 作品。用 three.js 构建为单个 HTML，运行时零外部请求，双击即可离线打开。

## 内容

- 10 栋建筑 + 400m 标准运动场，用地 460m × 360m，1 单位 = 1m
- day ∈ [0, 720] 为唯一时间状态，所有几何均为 day 的纯函数，seek 同步幂等
- 施工准备 → 三批次开工 → 分批移交 → 室外工程 → 竣工验收
- HUD：天数、日期、阶段、进度、可拖拽时间轴、播放/速度、施工总控甘特图（点击工序跳转）
- 天气 × 时段：晴 / 多云 / 阴 / 雨 / 雾，清晨 / 正午 / 黄昏 / 夜
- 机位：无人机环绕 + 总图 / 入口人视 1.6m / 运动场 / 十栋楼近景，共 13 个预设
- 程序化城市、道路、远山、云、天空与夜间灯火；塔吊、外架密目网、基坑、堆场、工人与工程车

## 使用

直接打开 `校园建造720天.html`。

- 拖拽旋转、滚轮/双指缩放，双击回到总图
- `1`–`9`、`0` 切换机位，`Space` 播放/暂停，`H` 隐藏 HUD
- URL 参数：`?day=210&weather=rain&tod=night&cam=B04&hud=0&still=1`

## 截图脚本

```bash
npm install
node screenshots.js --days=0,210,360,520,720 --weather=clear,rain --tods=noon,night --cams=overview,entrance,field,B04,B07,B10
```

依赖本机 Chromium，默认路径 `/usr/local/bin/chromium`，可通过 `CHROME` 环境变量覆盖。输出到 `shots/`；页面报错会以非零状态退出。
